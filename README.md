# CodeAlpha - Data Visualization Project

## Project Overview
This project is part of the Data Analytics Internship at CodeAlpha.

The project focuses on transforming raw Netflix dataset information into meaningful visual insights using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created
1. Movies vs TV Shows Distribution
2. Top 10 Countries with Netflix Content
3. Netflix Content Growth Over Years

## Project Features
- Data visualization using charts and graphs
- Trend analysis
- Insight generation from raw data
- Automatic image saving
